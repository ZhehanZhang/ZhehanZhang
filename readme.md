## What I'm building
 
**OurHarbor** · *TypeScript, Python, Docker* · private
A research harness that runs AI coding agents (Codex, Claude Code, Gemini CLI) on open math problems. Each problem goes through three stages: an agent attempts it and writes a report, a second turns the report into a knowledge graph, and a third scores it against the team's rubric. Every attempt is sandboxed, logged, and kept. Built for a group of mathematicians; the repo is private because their work is unpublished.
 
**[Console Neo](https://github.com/ZhehanZhang/Console-Neo)** · *Electron, JavaScript* · beta
A desktop app for chairing Model UN committees, rebuilt from the open-source Console Lite. In use by chairing teams at my high school. AGPL-3.0.
 
**[zhehanz.com](https://zhehanz.com)** · *Kirby CMS, Astro*
My personal site: Kirby CMS with a heavily reworked Astro-based theme. Open-source release planned.
 
**Self-hosted services** · *Linux, Docker, Cloudflare*
Servers in Hong Kong, the US, and Romania running [nfls.pub](https://nfls.pub), a Discourse forum for the NFLS community, and a modified Z-Push server that gives Gmail real push in the stock iOS Mail app.
